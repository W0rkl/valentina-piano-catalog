# каталог нот — демонстрационный пример

прототип интерфейса для просмотра и обсуждения с валентиной кеврой. это не официальный магазин.

статический html/css/javascript без сервера приложений, форм заявки, учётных записей и приёма платежей. избранное и настройки оформления хранятся в браузере посетителя. ссылки ведут на оригинальные публикации автора.

источники публичных образцов: assets/provenance.json. лицензии шрифтов находятся в assets. права на произведения и изображения этим репозиторием не передаются.

размещение: github pages, ветка main, корень репозитория; .nojekyll отключает обработку генератором.

это временная демонстрация, не выбранный хостинг для коммерческого запуска. перенос с исходного статического каталога без изменения поведения.
